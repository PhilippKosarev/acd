# acd
A Python library and cli for reading and writing Assetto Corsa Data (.acd) files.

## Installing
In-development version:
```sh
pip install git+https://github.com/PhilippKosarev/acd.git
```
A stable version should be coming soon.

## Using the library
Here is a simple example which reads an acd file and prints the first value:
```python
import acd
input_file = './data.acd'
data = acd.read_file(input_file)
keys = list(data.keys())
first_key = keys[0]
print(data.get(first_key))
```

Here is a simple example for writing an acd file:
```python
import acd
output_file = './data.acd'
data = {'example-filename.txt': 'Hello from the example-filename.txt!'}
acd.write_file(output_file, data)
```

For reading from and writing to `bytes` or `bytearray` there is `acd.read_bytes` and `acd.write_bytes`. If you need to read from or write to a file object then you can use `acd.read_from_file_object` and `acd.write_to_file_object`. Unlike `acd.read_file` and `acd.write_file` these functions require you provide them the encryption key manually. The encyrption key can be generated by either `acd.get_encryption_key_for_file` or `acd.get_encryption_key_for_string`.

## Note about the .acd file format
- Acd files do not have a magic number, so it might not be possible to determine whether a given file is an acd file.
- The encryption key is generated based on either the basename or the dirname of the acd file, so moving or renaming the file might make it impossible to decrypt the file.
